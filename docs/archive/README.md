# 文档归档区

这里存放已经过期或已落地的历史材料。归档文档只用于追溯，不作为当前产品、架构或 UI 的执行依据。

## 归档规则

- 一次性设计 prompt、概念图、旧截图、历史方案草案进入 `archive/`。
- 如果内容仍定义当前行为，应留在 `product/`、`architecture/`、`ops/` 或 `design/ui_brief.md`。
- 归档时保留原文件名，必要时用目录名说明来源。
- 新实现不能直接引用归档文档作为需求，除非用户明确要求恢复某个历史方向。
